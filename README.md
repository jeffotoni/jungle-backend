# jungle-backend-challenge

Initial implementation scaffold for the Jungle Gaming Backend Developer - Go technical challenge.

This repository intentionally starts with:
- API / Consumer / Publisher as separate binaries
- Uber Fx lifecycle
- Quick HTTP boundary
- Jefferson Otoni structured logger boundary
- pgx/PostgreSQL
- Money implemented without float32/float64
- PostgreSQL, Keycloak and LocalStack/SQS via Docker Compose
- initial financial/inbox/outbox schema

The detailed LLM/CLI context is under `../agentesCli`.
